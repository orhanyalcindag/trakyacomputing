# Trakyacomputing - Bütünleşik BT Çözümleri Ajansı

Trakya bölgesinin (Lüleburgaz, Tekirdağ, Çorlu, Kırklareli, Çerkezköy, Edirne) önde gelen entegre teknoloji ve bilişim çözümleri kurumsal web platformu.

## 🚀 Proje Mimarisi ve Özellikler

- **Framework**: Next.js 16 (App Router) & React 19
- **Stil & Tasarım**: Tailwind CSS v4, Modern Dark/Light Mode, Cam Efekti (Glassmorphism), Siber Izgara Deseni ve Neon Işıma Animasyonları
- **Tipografi & Renk Paleti**:
  - **Derin Lacivert**: `#070d19` & `#0d1726`
  - **Gümüş Gri**: `#f1f5f9` & `#94a3b8`
  - **Elektrik Mavisi & Cyan**: `#00f0ff` & `#38bdf8`
- **İkonografi**: Lucide React & Optimize Edilmiş Vektörler
- **State Yönetimi & Context**:
  - `ThemeContext`: Koyu/Açık tema geçişi, `localStorage` senkronizasyonu
  - `CartContext`: Dinamik e-ticaret sepet yönetimi, adet güncelleme, sipariş & WhatsApp entegrasyonu, teklif modalı tetikleyicisi

## 🛠️ Sayfa ve Bileşen Mimarisi

1. **Navbar & Header**: Kurumsal logo, çok sayfalı menü, sepet göstergesi ve sayaç rozeti, Dark/Light mode düğmesi, mobil drawer menü ve belirgin "Teklif Al" CTA butonu.
2. **Hero Section**: "Trakya'nın Bütünleşik Teknoloji ve Yazılım Çözüm Ortağı" ana başlığı, canlı istatistik sayaçları, etkileşimli bütünleşik BT terminal kartı.
3. **Hizmetlerimiz (Services Grid)**:
   - Yazılım & Otomasyon (C#, ASP.NET Core, React, Next.js)
   - Ağ ve Güvenlik Sistemleri (Hikvision/Dahua IP Kamera, NVR, Cisco/MikroTik Switch)
   - Donanım & E-Ticaret Tedariği (Kurumsal Sunucu, Anakart, İş İstasyonları, ECC RAM)
   - 3D Özel Çözümler (Saha montaj braketleri, PETG/Karbon 3D baskı aparatları)
4. **E-Ticaret Vitrini (Mini Mağaza Modülü)**:
   - Kategori filtreleme ve ürün arama
   - Canlı ürün özellikleri, indirim rozetleri, "Sepete Ekle" ve hızlı detay modalı
   - "Tıkla, Donanımı Al, Kurulumu Biz Yapalım!" bölgesel anahtar teslim montaj opsiyonu
5. **Neden Biz? / Avantajlarımız (Bölgesel Güç)**:
   - Lüleburgaz merkezli mobil teknik servis filosu
   - 30 dakikada yerinde acil arıza müdahalesi
   - 360° tek muhataplı bilişim ekosistemi
6. **Projelerimiz & Referanslar**:
   - Lüleburgaz OSB, Çorlu Tekstil, Kırklareli Entegre Çiftlik ve Edirne Lojistik Üssü vaka analizleri
7. **İnteraktif "Teklif Al" Modalı**:
   - İlgili hizmete göre otomatik dolan dinamik form ve anında geri bildirim bildirimi
8. **Footer**:
   - Lüleburgaz merkez adres konumu, telefon, e-posta, çalışma saatleri, sosyal medya ve hızlı linkler.

## 💻 Çalıştırma Talimatları

Geliştirme sunucusunu başlatmak için:
```bash
npm run dev
```

Üretim derlemesi (Production Build) almak için:
```bash
npm run build
```

Derlenmiş projeyi başlatmak için:
```bash
npm start
```
